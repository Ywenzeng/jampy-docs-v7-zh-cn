============
load_modules
============

.. js:function:: load_modules(module_array, callback)

**domain**: client 

**language**: javascript

**class** :doc:`AbstractItem </refs/client/abstractitem_api>`

Description
===========

在执行 **callback** 前， **load_modules** 方法会动态加载指定的多个模块。
该方法与 :doc:`load_module <m_load_module>` 的作用类似，不同处是会加载并初始化 **module_array** 中指定的实体项的所有模块。

Example
=======


下面，只有该实体项和它父项所拥有的模块都被加载后，才执行 do_some_work 函数：

.. code-block:: js

    function some_work(item) {
        item.load_modules([item, item.owner], do_some_work);
    }
    
    function do_some_work(item) {
        // some code
    }
