==========
item_by_ID
==========

.. js:function:: item_by_ID(ID)

**domain**: client 

**language**: javascript

**class** :doc:`AbstractItem </refs/client/abstractitem_api>`

Description
===========

item_by_ID 在项目的 :doc:`任务树 </programming/task_tree>` 的所有实体项中进行搜索，
从当前条目开始，查找其 :doc:`ID <at_id>` 属性等于 ID 参数的实体项。
