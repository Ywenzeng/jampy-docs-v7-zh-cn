=======
visible
=======

.. js:attribute:: visible

**domain**: client 

**language**: javascript

**class** :doc:`Filter class </refs/client/filter_api>`


Description
===========

如果未指定 **filters** 选项，那么此属性为 **true** 时，
过滤器的输入控件会被 :doc:`create_filter_inputs </refs/client/item/m_create_filter_inputs>` 方法创建。
