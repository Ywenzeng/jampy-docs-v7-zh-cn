=====
value
=====

.. js:attribute:: value

**domain**: client 

**language**: javascript

**class** :doc:`Filter class </refs/client/filter_api>`


Description
===========

使用 **value** 属性来获取或设置过滤器的值。

Example
=======

.. code-block:: js

    function on_view_form_created(item) {
        item.filters.invoicedate1.value = new Date(new Date().setYear(new Date().getFullYear() - 1));
    }
