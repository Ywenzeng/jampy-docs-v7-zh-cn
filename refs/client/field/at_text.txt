====
text
====

.. js:attribute:: text

**domain**: client 

**language**: javascript

**class** :doc:`Field class </refs/client/field_api>`


Description
===========

使用 **text** 属性来设置或获取字段的文本值。

获取 text 属性的值
---------------------------

获取 :doc:`value <at_value>` 属性的值，并将其转换为文本。

设置 text 属性的值
---------------------------

按字段的类型对文本进行转换，并将字段的 :doc:`value <at_value>` 属性指定为转换后的值。
