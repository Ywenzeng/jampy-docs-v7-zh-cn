============
lookup_value
============

.. js:attribute:: lookup_value

**domain**: client 

**language**: javascript

**class** :doc:`Field class </refs/client/field_api>`


Description
===========

如果字段是 :doc:`查找字段 </programming/data/lookup_fields>` ，
获取到的是它的查找的值；否则，获取到的是 :doc:`value <at_value>` 属性的值。
