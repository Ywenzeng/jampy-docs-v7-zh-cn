========
required
========

.. js:attribute:: required

**domain**: client 

**language**: javascript

**class** :doc:`Field class </refs/client/field_api>`


Description
===========


指定一个字段的值是否必须是非空的。

使用 **required** 来判断一个字段是必须有一个值，还是可以为空。
当将 **required** 设置为 true ，试图保存 null 时，将会触发一个异常。
