=========
raw_value
=========

.. js:attribute:: raw_value

**domain**: client 

**language**: javascript

**class** :doc:`Field class </refs/client/field_api>`


Description
===========

表示一个字段对象中的数据。

使用 **raw_value** 只读属性直接从实体项的数据集中读取数据。
其他属性例如 :doc:`value <at_value>` 和 :doc:`text <at_text>` 会对字段数据进行转换。
因此， :doc:`value <at_value>` 属性将数值字段的 **null** 值转换为 **0**。
