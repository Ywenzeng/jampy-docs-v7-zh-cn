==========
field_type
==========

.. js:attribute:: field_type

**domain**: client 

**language**: javascript

**class** :doc:`Field class </refs/client/field_api>`


Description
===========

Identifies the data type of the field object.
指定字段对象的数据类型。

使用 **field_type** 属性来获取字段所包含的数据的类型，其值是下列值之一：

* "text", 
* "integer", 
* "float",
* "currency", 
* "date", 
* "datetime", 
* "boolean", 
* "blob"
